Moving from Premiere Pro is easier when you migrate commands deliberately. A familiar key can perform a different action in another preset, and a correct binding can still behave differently when the wrong panel has focus. This guide is a migration checklist; the [general shortcuts guide](/guides/filmcraft-shortcuts) covers a smaller beginner set.

The references below follow the official FilmCraft v0.20.1 keyboard documentation. Its Premiere-compatible reference uses macOS notation. Read Command as Command and Option as Option; check the actual Windows or Linux binding inside FilmCraft instead of assuming every modifier can be substituted.

<GuideHeading id="preset">1. Choose and back up a preset</GuideHeading>

Open **Edit → Keyboard Shortcuts…**. If you already changed bindings, export your current set before switching. Select **Premiere Pro Compatible** and inspect the command names for the actions you use every day. FilmCraft also has a **FilmCraft Default** preset; the names matter because these sets are not identical.

FilmCraft imports and exports its own JSON shortcut files. A Premiere `.kys` file cannot currently be imported. Keep your old Premiere configuration as a reference, then recreate only the bindings you need. Export the new FilmCraft set after checking it so a reinstall does not erase your work.

<GuideHeading id="practice">3. Run a small migration exercise</GuideHeading>

1. Save a separate practice project and place several clips on a sequence.
2. Click the Timeline, target the intended tracks, and move between edits with Up and Down. Compare the result with the any-track variants.
3. Put the playhead inside a clip and use Select Clip at Playhead. Confirm the highlight before changing anything.
4. Test one extend-edit command, play across the result, and undo it. Check that linked audio remains aligned.
5. Focus the Program monitor and test Export Frame. If the clip becomes disabled, return to the preset selector rather than assuming the export failed.
6. Export your verified custom shortcut JSON and store it with your editing setup notes.

<GuideHeading id="fix">
  4. Resolve conflicts before building muscle memory
</GuideHeading>

Finish typing in text and number fields before using application shortcuts. If the key still fails, try the command through its menu: a disabled menu command usually points to selection or context, while a working menu command points toward the binding or keyboard layout. Check both application-wide and panel-specific assignments before replacing a shortcut.
