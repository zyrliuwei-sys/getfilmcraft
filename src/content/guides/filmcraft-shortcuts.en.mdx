The most useful FilmCraft shortcuts are the ones that remove repeated interruptions from your editing. Start with playback, selection and a simple trim. Learn more only when a recurring action is slowing you down. A long list of unpractised keys is less useful than five you can use confidently.

This guide supports the [first-video tutorial](/guides/filmcraft-tutorial-first-video). If you are still learning the interface, use the [beginner walkthrough](/tutorial) alongside it, or return to the [FilmCraft homepage](/) for installation and browser options.

<GuideHeading id="preset">1. Check your shortcut preset first</GuideHeading>

Open **Edit → Keyboard Shortcuts…** and inspect the active set. FilmCraft has its own default layout and a Premiere Pro Compatible preset. They overlap, but they are not identical. The official [keyboard documentation](https://github.com/storytold/filmcraft/blob/main/docs/keyboard.md) gives one concrete example: **Shift+E** is Clip Enable in FilmCraft Default and Export Frame in the compatible preset.

Confirm the command name in your shortcut editor before learning a new combination. On macOS, references may use Command (⌘) and Option (⌥); Windows and Linux combinations should be checked in the app instead of mechanically replacing every symbol. Custom bindings and keyboard layouts can also change what you need to press.

Do not practise ripple operations on your only project copy. Save a duplicate, make the edit and immediately inspect what moved. If the result is surprising, use Undo before making another change; several small edits can hide the original mistake.

<GuideHeading id="practice">
  3. Practise a five-minute keyboard session
</GuideHeading>

Choose a short, disposable sequence. The objective is not to edit as fast as possible. It is to make the result predictable enough that you no longer need to think about each key.

1. Click the Timeline and start playback with Space. Stop at a useful moment.
2. Try J, K and L while watching both direction and speed. Stop before switching tasks.
3. Choose V and select one clip. Confirm the selection visually.
4. Perform one trim, replay the join, and undo it. Repeat until the result is easy to anticipate.
5. Move to a title and use T only when you intend to edit text. Exit text entry before returning to playback keys.

Practise the same tiny sequence twice. On the second pass, notice which mouse movement was unnecessary and which one established important context. A click to focus the correct panel is useful; removing it without understanding focus can make a shortcut less reliable.

<GuideHeading id="focus">
  4. Understand why panel focus changes a shortcut
</GuideHeading>

A shortcut is not simply a key attached to the whole application. FilmCraft supports panel-specific bindings. A text field can also consume a keystroke as input. Before diagnosing a broken command, look for the active panel, selected object and any open text entry.

For example, pressing a letter while typing a title should change the title. It should not be interpreted as a timeline tool command. Finish text entry, select the appropriate panel and try the action again. Likewise, moving a graphic layer and moving a timeline clip are different operations even if a preset uses similar modifier keys.

When you learn a command, remember the context with it: “select an edit point, then extend” is a better habit than remembering E alone. The same applies to source insertion: identify the source range and destination tracks before pressing the shortcut.

<GuideHeading id="customize">
  5. Customize deliberately and keep a copy
</GuideHeading>

Change one frequently used command at a time. Choose a combination that is comfortable on your actual keyboard, check for conflicts in the shortcut editor and test it in the intended panel. Avoid rebuilding the entire layout before you know which operations you use most.

FilmCraft's shortcut editor can export and import its own JSON presets. The official [keyboard reference](https://github.com/storytold/filmcraft/blob/main/docs/keyboard.md) states that Adobe `.kys` files cannot currently be imported. Selecting a Premiere-compatible layout inside FilmCraft is different from loading an exported Adobe keyboard file.

Export a copy after your custom set feels stable. Give the file a descriptive name and keep a brief note of the changes you made. That makes another computer or a future reinstall easier to set up. After updating the application, recheck the few commands you rely on most before starting a long session.

Keep your practice small and return to the [30-second editing exercise](/guides/filmcraft-tutorial-first-video) when you are ready to combine the shortcuts into a finished project.
